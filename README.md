# -Color-Detection-using-OpenCV
This is a simple Python project that uses OpenCV to detect colors using the camera 📷:




https://github.com/user-attachments/assets/d8b624c4-7a69-4199-a7df-22b256ff53e5


🎯 Project Idea
The program opens the camera and looks for objects with specific colors. When it finds a colored object, it draws a box around it and displays the color name.
The program detects:

🔵 Blue
🟢 Green
🟡 Yellow
🔴 Red
